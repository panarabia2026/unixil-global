# Unixil Global — Website

Corporate website for Unixil Global FZCO: industrial technical solutions in instrumentation, electrical, telecom and mechanical, including GRP cable trays and junction boxes for hazardous areas.

## Pages
- `index.html` — Home
- `solutions.html` — The five disciplines
- `products.html` — Product range with discipline filter (`?d=hazardous`)
- `industries.html` — Sectors served
- `about.html` — Company, values, QHSE, global presence
- `contact.html` — Contact details and enquiry form

## Structure
- `assets/css/styles.css` — design system and layout
- `assets/js/art.js` — inline SVG illustrations
- `assets/js/site.js` — header, footer, content data, filter and forms

Plain HTML, CSS and JavaScript with no build step. The enquiry form opens a pre-filled email to `info@unixil.com`.
